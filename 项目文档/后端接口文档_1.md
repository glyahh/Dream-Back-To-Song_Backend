# 梦回宋朝 · 后端接口文档（v1.0）

> 项目：梦回宋朝（宋韵文化主题小程序）  
> 后端技术栈：Spring Boot + MyBatis + MySQL  
> 文档用途：与前端《前端接口文档_1.md》对齐，说明后端实际实现的接口与字段。

---

## 一、通用约定

### 1.1 基础信息

- **基础路径**：`https://{API_DOMAIN}/api`
- **统一前缀**：所有 Controller 配置在 Spring Boot 中的 `context-path=/api`
- **字符编码**：UTF-8

### 1.2 鉴权方式

- 登录成功后后端返回 `token`，前端需在后续请求头中携带：

```http
Authorization: Bearer {token}
```

- 无需登录的接口已在下文「是否鉴权」中标明为「否」。

### 1.3 统一返回格式

所有接口返回结构如下：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code`：  
  - `0`：成功  
  - 非 0：业务错误码（见下表）
- `message`：提示信息
- `data`：业务数据（对象或数组）

#### 常用错误码约定

| code | 说明                   |
|------|------------------------|
| 0    | 成功                   |
| 400  | 参数错误或业务校验失败 |
| 401  | 未登录或 token 失效    |
| 403  | 无权限                 |
| 404  | 资源不存在             |
| 500  | 服务器内部错误         |

### 1.4 分页约定

- 请求参数：  
  - `page`（页码，从 1 开始，默认 1）  
  - `pageSize`（每页条数，默认 10）
- 响应格式（封装在 `data` 内）：

```json
{
  "list": [],
  "total": 0,
  "hasMore": false
}
```

## 二、认证模块

### 2.1 发送短信验证码

- **方法**：`POST`
- **路径**：`/auth/send-code`
- **鉴权**：否

**请求体**

```json
{
  "phone": "17316321225"
}
```

| 字段  | 类型   | 必填 | 说明       |
|-------|--------|------|------------|
| phone | string | 是   | 11 位手机号 |

**说明**

- 验证码为 6 位数字，有效期 5 分钟，服务端当前以内存缓存模拟（日志会输出验证码，方便开发联调）。

**响应**

```json
{
  "code": 0,
  "message": "验证码已发送",
  "data": null
}
```

---

### 2.2 验证码登录

- **方法**：`POST`
- **路径**：`/auth/login`
- **鉴权**：否

**请求体**

```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

| 字段  | 类型   | 必填 | 说明       |
|-------|--------|------|------------|
| phone | string | 是   | 11 位手机号 |
| code  | string | 是   | 6 位验证码 |

**响应**

```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 86400,
    "user": {
      "id": 1,
      "phone": "13800138000",
      "nickname": "138****8000",
      "avatar": null,
      "bio": null,
      "createdAt": "2026-01-01T00:00:00",
      "updatedAt": "2026-01-01T00:00:00"
    }
  }
}
```

---

### 2.3 退出登录

- **方法**：`POST`
- **路径**：`/auth/logout`
- **鉴权**：是

**说明**

- 鉴权采用 JWT 无状态方案，退出登录仅为前端语义操作，服务端不做 token 黑名单管理。

**响应**


### 3.2 更新用户资料

- **方法**：`PUT`
- **路径**：`/user/profile`
- **鉴权**：是

**请求体**

```json
{
  "nickname": "烟雨朦胧",
```

- **方法**：`POST`

- **鉴权**：是

**请求体**

- 表单字段：`file`（图片文件）

**响应**

```json
{
  "code": 0,
  "data": {

  }
}
```

> 当前实现中，文件未真正上传到存储服务，而是返回一个占位 URL；后续可替换为实际对象存储逻辑。
