# Domain 包结构说明

## 分类说明

### Entity（数据库实体类）

当前 `domain` 包下的所有类均为 **Entity（数据库实体类）**，用于 MyBatis 映射数据库表。

| 类名 | 对应数据库表 | 说明 |
|------|-------------|------|
| `User` | `users` | 用户表 |
| `UserSettings` | `user_settings` | 用户设置表 |
| `Product` | `products` | 商品表 |
| `ProductImage` | `product_images` | 商品图片表 |
| `ProductStyle` | `product_styles` | 商品款式表 |
| `CartItem` | `cart_items` | 购物车明细表 |
| `Address` | `addresses` | 收货地址表 |
| `Order` | `orders` | 订单主表 |
| `OrderItem` | `order_items` | 订单明细表 |
| `Logistics` | `logistics` | 物流信息表 |
| `Carousel` | `carousel` | 轮播图表 |
| `Topic` | `topics` | 话题表 |
| `Post` | `posts` | 帖子/动态表 |
| `PostImage` | `post_images` | 帖子图片表 |
| `PostLike` | `post_likes` | 帖子点赞表 |
| `UserFollow` | `user_follows` | 关注关系表 |
| `Collection` | `collections` | 收藏表 |
| `Creation` | `creations` | 创作表 |
| `Message` | `messages` | 消息通知表 |
| `PrivateMessage` | `private_messages` | 私信表 |
| `Feedback` | `feedback` | 意见反馈表 |

### DTO（Data Transfer Object - 数据传输对象）

**用途**：从前端接收请求数据的类

**当前实现**：DTO 类定义在对应的 Controller 中作为内部类（如 `AuthController.SendCodeRequest`、`UserController.UpdateProfileRequest` 等）

**建议**：如需统一管理，可在 `domain` 下创建 `dto` 子包，例如：
- `domain/dto/auth/LoginRequest.java`
- `domain/dto/user/UpdateProfileRequest.java`
- `domain/dto/order/CreateOrderRequest.java`

### VO（Value Object - 值对象）

**用途**：返回给前端的数据类

**当前实现**：VO 数据通过 Service 层返回 `Map<String, Object>` 或直接在 Controller 中构建

**建议**：如需统一管理，可在 `domain` 下创建 `vo` 子包，例如：
- `domain/vo/auth/LoginResponse.java`
- `domain/vo/user/UserProfileVO.java`
- `domain/vo/product/ProductDetailVO.java`

### Enum（枚举类）

**当前状态**：暂无枚举类

**建议枚举**：
- `OrderStatus`：订单状态（pending/paid/shipped/finished/cancelled）
- `CreationType`：创作类型（服饰设计/饮食随笔/建筑手稿/出行见闻/其他）
- `MessageCategory`：消息分类（system/social/order）
- `CollectionType`：收藏类型（goods/notes）
- `ProductType`：商品类型（new/series/normal）

**建议位置**：`domain/enums/` 子包

## 目录结构建议

```
domain/
├── entity/          # Entity 类（当前所有类可移至此目录）
│   ├── User.java
│   ├── Product.java
│   └── ...
├── dto/            # DTO 类（从前端接收）
│   ├── auth/
│   ├── user/
│   └── ...
├── vo/             # VO 类（返回给前端）
│   ├── auth/
│   ├── user/
│   └── ...
└── enums/          # 枚举类
    ├── OrderStatus.java
    ├── CreationType.java
    └── ...
```

## 当前实现说明

- ✅ **Entity**：已全部添加详细注释，标注为 Entity 类型
- ⚠️ **DTO**：当前在 Controller 中作为内部类定义
- ⚠️ **VO**：当前通过 `Map<String, Object>` 返回
- ⚠️ **Enum**：暂无枚举类

如需重构为独立 DTO/VO 类，可参考上述目录结构建议。
